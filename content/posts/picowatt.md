## はじめに
電池で動くロガーを作っていると、「スリープ中に何µA流れているか」「1回の測定で何mAh使うか」を測りたくなります。[積雪深ロガーの最初の記事](/posts/snowdepth_logger/)では、NordicのPower Profiler Kit 2（PPK2）を使ってこれを測りました。

今回は、PPK2のように電流の時間変化を記録できる消費電力計を、Raspberry Pi Pico 2とTIのINA228で自作しました。名前は **picowatt** です。ファームウェア、PCアプリ、キャリア基板のKiCadデータは [GitHub (0kam/picowatt)](https://github.com/0kam/picowatt) で公開しています（GPL-3.0）。

[積雪深ロガーの続編](/posts/snowdepth_logger2/)の電流測定も、すべてpicowattで行っています。

## できること

- **消費電力の測定**：INA228 1枚で、測定対象の電圧・電流・電力をリアルタイムに記録
- **DC-DCコンバータの効率測定**：INA228 2枚で入力と出力を同時に測り、効率を計算
- **任意区間の積算**：グラフ上で範囲を選ぶと、その区間の電力量（Wh）と電荷量（Ah）を計算
- **CSVでの記録**：全サンプルをCSVに保存。GUIなしのコマンドラインでも記録可能
- **単体での表示**：PCにつながなくても、OLEDに電圧・電流が表示される

## 構成

| 役割 | 部品 | 備考 |
|---|---|---|
| マイコン | Raspberry Pi Pico 2（RP2350） | USBでPCに接続 |
| 電力モニタ | Adafruit INA228 ×2 | 15 mΩ（0.1%）のシャント抵抗、20ビットADC |
| ディスプレイ | SSD1306 128×64 OLED（I2C） | 秋月 |

INA228もOLEDも、すべてPico 2のI2Cバス（1 MHz）につないでいるだけです。電流はハイサイド（電源の＋側）に入れたシャント抵抗で測ります。

```
電源(+) → INA228 VIN+ ─[15 mΩ]─ VIN− → 測定対象(+)
電源(−) ←─────────────────────────────── 測定対象(−)
```

ブレッドボードで組む場合は、こんな配線になります（図はリポジトリのREADMEから）。

![ブレッドボードでの配線（消費電力測定）](/images/picowatt/breadboard-power.svg)

### キャリア基板
ブレッドボードだと配線が抜けやすいので、Pico 2・INA228×2・OLEDをソケットで挿すだけのキャリア基板も作りました。92×70 mmの2層基板で、電源とI2Cを配るだけの単純なものです。測定する電流はINA228モジュール自身のネジ端子台を通り、キャリア基板の配線には流れません。

## 使い方
ファームウェアは[Releases](https://github.com/0kam/picowatt/releases)からUF2をダウンロードし、Pico 2のBOOTSELボタンを押しながらUSBでつないで、出てきたドライブにコピーします。PCアプリはPyPIで公開しているので、[uv](https://docs.astral.sh/uv/)があれば1行で起動できます。

```bash
uvx picowatt
```

GUIで「Connect → Start」を押すと、電圧・電流・電力のグラフがリアルタイムに流れ始めます。「Measure」にチェックを入れると、グラフ上に範囲（緑の帯）が出ます。この範囲をドラッグすると、右のパネルにその区間の平均電圧・平均電流・平均電力と、電力量（Wh）・電荷量（Ah）が表示されます。

![picowattのGUI](/images/picowatt/picowatt_gui.png)

上のスクショは、測定端子に何もつながっていない状態です。そのため、グラフはゼロ付近のノイズだけになっています。

コマンドラインで記録する場合は次のようにします。

```bash
uvx --from picowatt picowatt-cli --seconds 10 --csv out.csv
```

### 測定レンジとサンプリングレート
INA228には測定レンジが2つあり、小さい電流を測るときは低電流レンジに切り替えます。

| レンジ | 分解能 | フルスケール |
|---|---|---|
| 通常 | 8 µA | 約4.2 A |
| 低電流 | 2 µA | 約1.05 A |

サンプリングレートは、INA228の変換時間と平均化回数の組み合わせ（プリセット）で選びます。速くするほどノイズが増えるので、測りたいものに合わせて選びます。

| プリセット | サンプリングレート | 用途の例 |
|---|---|---|
| fast | 約3,300 Hz | 数msの突入電流など、速い変化を見たいとき |
| normal | 約930 Hz | 一般的な測定 |
| quiet | 約120 Hz | 測定サイクル全体を長時間記録したいとき |
| very-quiet | 約7.6 Hz | µA級のスリープ電流 |

I2C経由で読んでいるので、PPK2（100 kSa/s）ほど速くはありません。数µs〜数百µsの細かい電流の変化は追えませんが、ロガーの「スリープ → 起きて測定 → スリープ」くらいの時間スケールなら十分です。ただし、突入電流のような数msの現象のピーク値を正しく測りたい場合は、fastにしておく必要があります。

## 精度の確認
安定化電源と電子負荷（ET5410A+）を使って確認しました。

| 項目 | 結果 |
|---|---|
| 電流（0.5 A、校正なし） | 電子負荷の設定値に対して −0.04% |
| 電流（約2 A、1点ゲイン校正後） | +0.04% |
| 電力量の積算（GUIとCSVからの再計算） | 一致度 0.04% |
| 効率モードのヌルテスト（2つのシャントに同じ電流を流す） | 99.84%（理想は100%） |
| DC-DCコンバータ（M78AR05-1、12 V入力）の効率 | 最大約92%（データシートの代表値とほぼ一致） |

シャント抵抗の実際の値は公称値から少しずれることがあるので、既知の電流で1点校正できるようにしています。校正値はボードごとにPCに保存され、接続時に自動で適用されます。

## µA級の電流を測るときの注意
15 mΩのシャント抵抗では、**1 µVの電圧が67 µAに相当**します。そのため、端子の熱起電力などで、何もつないでいなくても数十µAのオフセットが出ます。しかも、配線に触ったりつなぎ直したりすると、オフセットが数十µA動きます。

そこで、ゼロ点校正の機能をつけました。測定対象を外した状態で一定時間（既定10秒）平均し、その値をオフセットとしてレンジごとに保存します。µA級のスリープ電流を測るときは、次のようにすると安定します。

- 低電流レンジ・very-quietプリセットで測る
- ゼロ点は長めに（40〜60秒）平均する
- ゼロ点を取ったあとは、端子や配線に触らない
- 厳密にやりたいときは、同じセッション内で「測定対象を外して測る → つないで測る」を続けて行い、差を取る

積雪深ロガーの基板版では、保存したゼロ点を適用したまま、低電流レンジ・quietプリセットで1時間記録しました。約42万サンプルを平均して、スリープ電流は **31.7 µA（標準誤差0.2 µA）** でした。

### よくある間違い：電源の−をつなぎ忘れる
INA228は、電源電圧を自分のGNDピン基準で測ります。そのため、電源の−をpicowattのGNDにつなぎ忘れると、基板が電源から浮いてしまいます。電源電圧の表示が、0 Vとマイナス数十Vの間を50/60 Hzで振動するようになります（実際にはない電圧です）。電流はそれらしい値が出るので、気づきにくいのが厄介です。GUIとコマンドラインのどちらも、この状態を検出すると警告を出すようにしました。

## おわりに
INA228とPico 2で、µAのスリープ電流から数Aまで測れる消費電力計ができました。部品は手に入りやすいものばかりなので、電池で動くものを作っている人は、ぜひ作ってみてください。
